# 否定文リライト判定

否定文と書き換え文を1件ずつ比較し、意味保持・自然性・否定範囲を判定するローカルWebアプリです。Python 3.9以上を使用します。

## 起動（Windows / PowerShell）

uv をインストールした環境で、プロジェクトのディレクトリから実行します。

```powershell
uv sync --locked
uv run app/server.py
```

ブラウザで http://127.0.0.1:5000 を開きます。停止はターミナルで `Ctrl+C`。2回目以降は最後の起動コマンドだけで利用できます。

依存関係は `pyproject.toml` と `uv.lock` で管理します。`uv sync --locked` はロックファイルに従って `.venv` を作成・同期します。依存関係を追加するときは `uv add パッケージ名` を使い、更新された両ファイルをコミットしてください。

## 判定方法

- 元の文の削除箇所を打消線、書き換え文の追加箇所を色付き下線で表示します。
- 意味保持・自然性・否定範囲それぞれのOK / NGをクリックすると即時保存します。「解除」で未判定に戻せます。否定範囲は「OK＝変わっている」「NG＝変わっていない」です。
- コメントは入力が止まって650ミリ秒後、または文を移動する前に保存します。保存エラーは画面に表示し、未保存のコメントは画面に保持します。同じ操作や追加入力で再試行できます。
- 3項目すべてに判定を入れた文を「判定済み」と数えます。コメントだけでは判定済みになりません。既存の評価・コメントは保持し、否定範囲が未評価の文は未判定として扱います。
- フィルタで全件・未判定・意味NG・不自然・否定範囲NG・NG全部を切り替えられます。判定により条件から外れた文は表示対象から外れます。
- 「未判定へジャンプ」は全件から次の未判定を探します。末尾に達したら先頭から探します。
- 「3項目の判定後、次の未判定へ」をオンにすると、3項目の判定が揃ったとき自動で移動します。移動先がある場合はフィルタを「すべて」に戻します。設定はブラウザに記憶します。
- キー `1` / `2` は意味OK / NG、`3` / `4` は自然OK / NG、`5` / `6` は否定範囲OK / NG、`←` / `→` は前後へ移動します。入力欄やボタン等の操作中はショートカットを適用しません。
- 参考情報は折りたたみ表示です。候補のうち全行同じ値の列は、起動時の判定で自動的に除外します。

## 保存とバックアップ

`input/04_natural.csv` を直接更新し、不足している判定列（`meaning_preserved`、`naturalness`、`negation_scope`、`review_comment`、`reviewed_at`）を末尾に追加します。起動・閲覧だけではCSVを書き換えません。既存列は文字列として読み込み、空欄・数値の表記・改行・引用符を保持します。出力はUTF-8 BOM付き・CRLFです。

起動後の初回保存時と、前回バックアップから5分以上経過した保存時に `input/.backup/` に保存前のCSVをコピーします。ファイル名には時刻とマイクロ秒を付け、直近10世代を保持します。一時ファイルをディスクに書き出してからアトミックに置換し、成功したときだけメモリ内の判定値を確定します。

設定変更は起動前に環境変数で指定します。

```powershell
$env:BACKUP_COUNT = "10"
$env:BACKUP_INTERVAL_SECONDS = "300"
uv run app/server.py
```

復元するときはサーバーを停止し、必要なバックアップを `input/04_natural.csv` にコピーして再起動してください。起動中はメモリ上のデータが正になるため、CSVを外部編集する場合も先にサーバーを停止してください。単一プロセス・単一利用者向けです。サーバーは `127.0.0.1` のみにバインドします。

## API

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/items` | ID・行番号・判定値の配列 |
| GET | `/api/items/<instance_id>` | 文・文字差分・参考情報・判定値 |
| PUT | `/api/items/<instance_id>/review` | 判定・コメントの部分更新。`{item, saved: true}` を返す |
| GET | `/api/progress` | 全件数・判定済み・未判定・各NG件数 |

PUTは `meaning_preserved` / `naturalness` / `negation_scope`（`"OK"`, `"NG"`, `""`）と `review_comment`（文字列）を受け付けます。未知のIDは404、不正な更新は400、保存失敗は500を返します。

## 検証

```powershell
uv run python -m unittest discover -s tests -v
node --check static/app.js
```

テストでは一時ディレクトリにコピーしたCSVのみを使用し、既存55列の全セル保持・保存後の再読込・バックアップ世代管理・保存失敗時の整合性・APIの入力検証・参考情報の動的除外を確認します。
